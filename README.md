# Weather Dashboard

Приложение для отображения погоды с параллельной загрузкой данных.

## Функциональность

- Загрузка температуры, влажности, ветра
- Вычисление индекса погоды
- Кнопка обновления
- Имитация ошибок
- Автообновление каждые 10 секунд

## Технологии

- Kotlin, Coroutines, Flow
- Jetpack Compose
- ViewModel, StateFlow

## Контрольные вопросы (кратко)

**A) launch vs async**

| Метод | Возвращает | Когда использовать |
|-------|-----------|-------------------|
| launch | Job | Задача без результата |
| async | Deferred<T> | Нужен результат |

**B) suspend функция** — может приостанавливаться. Нельзя вызывать из обычной функции. `delay()` не блокирует поток, в отличие от `Thread.sleep()`.

**C) Диспетчеры**

| Диспетчер | Задачи |
|-----------|--------|
| Main | UI |
| IO | Сеть, БД |
| Default | Тяжёлые вычисления |

Если выполнить тяжёлые вычисления на Main — UI зависнет.

**D) Ошибки в корутине** — без обработки приложение крашится. Нужен `try-catch` внутри `launch`.

**E) viewModelScope** — автоматически отменяет корутины при уничтожении ViewModel.
